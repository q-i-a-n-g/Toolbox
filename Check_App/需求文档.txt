================================================================================
                    check.app 需求文档（综合版）
================================================================================

【项目简介】
制作一个 Mac 上的 app，名字为 check.app，运行后生成 Excel 文件 `result.xlsx`。
- data 文件夹下的所有 Excel 文件均由用户手动提供，app 不做网页模拟点击和自动下载。
- 交付形式为可直接双击运行的 `.app`，不能要求用户额外安装 Node / Python / Playwright 等环境。
- 输出文件：`result.xlsx`（位于 app 同级目录；如已存在同名文件则覆盖）。
- 不生成 app.log，不写任何日志文件。


【两阶段使用方式（固定流程）】
1. 首次运行：data 文件夹初始仅有基础任务文件（见下方定义）。
   运行 app 后仅生成一个 Sheet（拼链接）的 result.xlsx。
2. 用户手动操作：点击「拼链接」中的链接，在网页中手动下载其他所需 Excel 到 data 文件夹。
3. 第二次运行：再次双击运行 app，生成最终版 result.xlsx（完整结果）。


================================================================================
1. SHEET 生成规则
================================================================================

【基础任务文件定义】
以下文件中任意一个（或多个）都可作为基础任务文件：
  - 答+周.xlsx（含 Sheet1 和 Sheet2）
  - 答+周.xlsx 拆分为两个独立文件（文件名可任意）时，通过以下方式区分：
    - B 列"任务名称"中含"答题卡"的行所在 Sheet → 视为 Sheet1（答题卡链接用）
    - B 列"任务名称"中不含"答题卡"的行所在 Sheet → 视为 Sheet2（分数链接用）
  - 寒假.xlsx、秋季.xlsx、暑假.xlsx 中任意一个（只有一个 Sheet，用于 Sheet2）

基础任务文件用于：
  - 生成 Sheet1 的两个链接（拼链接）
  - 通过「子任务ID」→ 匹配「负责人」（E 列 子任务ID → M 列 负责人）

特别说明：文件名可变，优先按文件名匹配，找不到则按表头名匹配（匹配到"负责人"列即可）。


----------
Sheet1: 拼链接
----------
链接1 「分数+固定_全链接」：来源于基础任务文件的 Sheet2，把 D 列「任务ID」的数据去重，拼成链接：
  https://mapi.yuanfudao.com/evaluation/#/evaluation/holepage/statistics?taskIds=[65530,65531,65532]

链接2 「答题卡_链接」：来源于基础任务文件的 Sheet1，把 D 列「任务ID」的数据去重，拼成链接：
  https://mapi.yuanfudao.com/evaluation/#/evaluation/cardPage/statistics?taskIds=[65615,65653]

注：
- 当 data 文件夹中仅有「分数/固定类」文件（无答题卡 Sheet1）时，答题卡链接为空。
- 两个链接的数据来源是两个不同的 Sheet（Sheet1 和 Sheet2），若拆分成两个文件，需通过「任务名称」列中是否含"答题卡"来区分。


----------
Sheet2: 分数识别错误或忽略
----------
来源：data/分数.xlsx（表头匹配）
筛选条件：
  - K 列「是否有分数框」= 「有分数框」
  - L 列「分数识别情况」= 「忽略」或「错误」
处理流程：
  1. 按 S 列「链接」去重
  2. 通过 A 列「子任务id」匹配「负责人」
  3. 转换链接：#/admin/evaluation/holepage/... → #/evaluation/holepage/...（新列「兼职用的链接」）
格式设置：
  - K、L 列表头加浅黄色底色


----------
Sheet3: 固定批改错误或忽略
----------
来源：data/AI.xlsx（表头匹配）
筛选条件：
  - C 列「任务名」包含「固定」
  - X 列「固定批改识别结果」= 「忽略」或「错误」
处理流程：
  1. 按 AL 列「链接」去重
  2. 通过「子任务id」匹配「负责人」
  3. 转换链接（同上）
格式设置：
  - X 列表头加浅黄色底色


----------
Sheet4: 题目框错误+忽略超过3个
----------
来源：data/AI.xlsx（表头匹配）
筛选条件：
  - M 列「题目框识别情况」= 「错误」或「忽略」
  - 二次筛选：「忽略」记录中，相同「链接」下不同「大题ID」出现 ≥ 3 个，才保留（错误的全部保留）
处理流程：
  1. 按「链接」去重
  2. 通过「子任务id」匹配「负责人」
  3. 转换链接（同上）
格式设置：
  - M 列表头加浅黄色底色


----------
Sheet5: BadCase
----------
来源：data/AI.xlsx（表头匹配），输出 AI.xlsx 的完整列（全 38 列），不隐藏任何列。
筛选条件：
  - P 列「批改情况」= 「错误」
  - V 列「是否AI可批」= 「AI可批」
  - W 列「作答结果-算法可解评测结果」= 「是」
处理流程：
  1. 通过「子任务id」匹配「负责人」（从基础任务文件），在末尾追加三列：
     - AM 列「负责人」：从基础任务文件匹配
     - AN 列「是否修改」：列头仅展示文字，除表头外内容为空（无下拉按钮）
     - AO 列「检查人」：内容为空
  2. 不加「兼职用的链接」列
  3. AO 列中间单元格加绿色底色：数据行总数 N，给第 round(N/2) 行的 AO 列加绿色（纯绿 #00FF00）
格式设置：
  - P、V、W 列表头加浅黄色底色
  - 不隐藏任何列


----------
Sheet6: 答题卡_分数识别错误或忽略
----------
来源：data/答题卡-分数.xlsx（表头匹配）
筛选条件：
  - J 列「是否有分数框」= 「有分数框」
  - K 列「分数识别情况」= 「忽略」或「错误」
  - L 列「分数-算法可解评测结果」= 「是」
处理流程：
  1. 按 M 列「链接」去重
  2. 通过「子任务id」匹配「负责人」
  3. 转换链接：#/admin/evaluation/cardPage/... → #/evaluation/cardPage/...（新列「兼职用的链接」）
格式设置：
  - J、K、L 列表头加浅黄色底色


----------
Sheet7: 答题卡_AI_错误次数≥3
----------
来源：data/答题卡-AI.xlsx（表头匹配）
筛选条件：
  - N 列「批改情况」= 「错误」
  - P 列「作答结果-算法可解评测结果」= 「是」
  - 二次筛选：不同「链接」中，同一个「大题ID」出现 ≥ 3 个，才保留
处理流程：
  1. 按 Y 列「链接」去重
  2. 通过「子任务id」匹配「负责人」
  3. 转换链接：#/admin/evaluation/cardPage/... → #/evaluation/cardPage/...（新列「兼职用的链接」）
格式设置：

3. 数据处理规则
================================================================================

【文件匹配规则】
- data 文件夹中所有 Excel 文件的名字、Sheet 名字都可变
- 匹配优先级：先按文件名匹配，找不到再按表头匹配（匹配到"负责人"列即可认定是基础任务文件）
- 匹配需快速，只读首行表头

【答+周 拆分兼容】
- 若 data 文件夹下有 ≥2 个文件，且其表头相同、均含基础任务文件特征（含"负责人"列）
- 通过 B 列「任务名称」是否含"答题卡"来区分两个 Sheet

【筛选与去重规则】
- 所有筛选操作均基于表头名称，不依赖列位置
- 去重：按指定列的唯一值进行去重（保留第一条）
- 如无匹配结果：保留表头，数据行为空

【阶段化生成规则】
1. 仅检测到基础任务文件 → 只生成 Sheet1（拼链接）
2. 检测到其他明细文件 → 按可用文件继续生成对应 Sheet
3. 所有文件齐全时 → 生成完整最终版 result.xlsx

【错误处理规则】
- 筛选后无数据：保留该 Sheet 的表头
- 匹配失败（子任务id 无对应负责人）：相关列内容为空
- 文件不存在：跳过对应 Sheet，终端提示用户补齐后再次运行
- 表头不匹配：尝试按表头名匹配；仍失败则跳过


================================================================================
4. 输出格式要求
================================================================================

【全局格式】
- 所有 Sheet 的所有单元格字体：等线，12 号
- 所有列自动调整列宽为最佳列宽（按内容宽度，中文字符按2宽度计）
- 例外：「拼链接」Sheet 的 B 列（链接列）不自动调整列宽

【数据源文件重命名（运行结束前）】
若 data 文件夹中存在表头可识别但文件名不规范的 xlsx 文件，按以下规则重命名：
- 含「题目框识别情况」+「是否有分数框」+「大题ID」→ 分数.xlsx
- 含「阶段」+「科目」+「任务名」→ AI.xlsx
- 含「答案框识别情况」+「分数框识别情况」但不含「题目框识别情况」→ 答题卡-分数.xlsx
- 含「任务名」+「任务id」+「手写识别」但不含「阶段」→ 答题卡-AI.xlsx

6. 交付形式
================================================================================

- 名字：check.app
- 双击即可运行，无需安装任何 Python / Node / 依赖环境
- 使用 PyInstaller 打包为独立可执行文件
- 目录结构：
  check.app/
  └── Contents/
      ├── MacOS/
      │   └── check（zsh 入口脚本，负责弹出 Terminal）
      └── Resources/
          └── check_main（PyInstaller 打包的主程序，含所有逻辑）
